What is CSS? Time: 2:30:25

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the presentation and design of a document written in HTML or XML. CSS allows web developers to control the layout, colors, fonts, spacing, and overall visual appearance of web pages. By separating content (HTML) from presentation (CSS), it enables more flexibility and maintainability in web design.

For writing CSS, there is a basic syntax: Selector {
  property: value;
}
Selector: This specifies the HTML element(s) you want to style. It can be an element type, class, ID, or a combination of these.
Property: This is the aspect of the element you want to change, such as color, font-size, margin, etc.
Value: This is the specific setting you want to apply to the property, such as a color code, pixel value, percentage, etc.

Position Porperty within CSS. 
There are four different position settings to set different elements to a speacific position. Named: Static, Relative, Absolute, Fixed, Sticky. Note: thier are four properties to set within position property, which are: top, bottom, right, left. 

  1. Static: This is the default position of any element which is the position 
  selected relatie to the document. It stays the same whether or not you add this  
  to your element.
  
  2. Relative:  This changes the element position from static to the current 
  orientation. which means now you can add top, bottom, right, left  shifting using 
  the four speacific properties. Which will change its current orientation by the 
  speacific property. They are always going to overlap any static element. 

  3. Absolute: This sets the element's position to the nearest non-static ansester 
  elememt. which means the element on which we are applying this property, it will 
  move according to its parent or other ansestor element. 

  4. Fixed: This sets the element position relative to the browser, not the 
  document or any element. This fixes the position of the element relative to the 
  user's page. which means if the user scrolls, the element follows the movement. 

  5. Sticky: This sets the element's position relative to the user page, if the 
  user scrolls, the element shall follow it.
  
  Note: If the element is present below in the document, as soon as the user 
  scrolls through the element, it sticks to the top of the page.  

Z-index Property: This decides which element shall overlap other elements. The larger the z-index, it will overlap the smaller ones. This basically means to give the priority to the element. This property comes from math z-axis formula.
