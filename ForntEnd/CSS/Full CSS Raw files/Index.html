07 / Responsive design

Responsive Design Challenge

Responsive CSS adapts a page to different screen sizes. Use media queries to adjust the navigation, card layout, spacing, or type size when the viewport gets narrower.

Your challenge

Make the cards stack on small screens, keep text readable, and ensure there is no horizontal scrolling.

  • Start with a flexible layout.
  • Add a breakpoint only when the design needs one.
  • Test with keyboard navigation and browser zoom.

Keep experimenting: small CSS changes make visible differences.
